# rk-iva

在 **RK3588 Linux aarch64** 上，进入本 skill 的 `scripts/` 目录后执行 `run.sh`。

## 参数说明

| 参数 | 必选 | 说明 |
|------|------|------|
| `-i <path>` | 否 | 输入图像路径。支持 jpeg/png；也支持 `.yuv`/`.data`/`.bin` 格式（NV12 raw，需配合 `-W`/`-H` 指定宽高）。**省略时自动从摄像头抓取一帧** |
| `-o <path>` | **是** | 输出图像路径。检测完成后，带有检测框的结果图会保存到此路径 |
| `-h` | 否 | 打印帮助信息 |

## 用法示例

对本地图像做检测：

```bash
./run.sh -i 0000.jpg -o /tmp/out.jpg
```

从摄像头抓一帧并检测（自动探测摄像头）：

```bash
./run.sh -o /tmp/out.jpg
```

## 权限限制
- 你**没有权限**调用 `sessions_spawn` 工具
- 所有任务必须在当前会话内完成，不得创建子 Agent
- 如果用户要求需要并行处理的任务，请使用串行方式逐步完成

## 输出说明

### 1. 结果图像

检测框标注后的图像保存在 `-o` 指定的路径。

### 2. 标准输出（stdout）

日志中 `detect results:` 之后逐行输出每个检测目标，格式如下：

```
cls=<类别> score=<置信度> box=(x1 y1 x2 y2)
```

**字段含义：**

| 字段 | 类型 | 说明 |
|------|------|------|
| `cls` | 字符串 | 检测类别：`PERSON`（人形）、`PET`（宠物）、`VEHICLE`（机动车/车辆）、`NON_VEHICLE`（非机动车） |
| `score` | 整数 0–100 | 置信度，越高表示检测越可信 |
| `box` | 四元组 (x1 y1 x2 y2) | 目标包围框的左上角 (x1, y1) 和右下角 (x2, y2) 像素坐标，坐标数值为万分比（0-9999），例如5000表示图像的中心 |

**示例输出：**

```
detect results:
cls=PERSON score=92 box=(1200 450 3800 5200)
cls=VEHICLE score=87 box=(5000 5000 6000 6000)
```

## 完成后操作

执行完成后，**必须**将以下内容发送给用户：

1. **结果输出图像** — 将输出的`-o` 指定的结果图像文件发送给用户对应的频道。
2. **检测结果文字** — 解析 stdout 中 `detect results:` 后的内容，如果有目标以易读的方式告知用户检测到了哪些目标（类别、置信度、位置），如果没有则告诉用户没有检测到目标。

**注意事项**

- 每次都需要重新抓取一张图像检测，禁止直接使用上次结果
- 执行错误直接将错误告诉用户
- 如果没有目标则直接告诉用户没有检测到目标，禁止虚构结果
- 对于 `-o` 生成的结果图，直接将图像文件发送给用户，不要去读取、解析或转述输出图像文件内容。
- **通过 QQBot 发送文件**：**必须**使用 `<qqfile>绝对路径</qqfile>` 格式，标签内不能有 `path=` 属性！
 - ✅ 正确：`<qqfile>/tmp/out.jpg</qqfile>`
 - ❌ 错误：`<qqfile path="...">文件名</qqfile>`
