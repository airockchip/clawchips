# Skills Directory

| Skill | Directory | Purpose | Typical Use |
|---|---|---|---|
| `rk-adb` | `rk-adb/` | Connects to Rockchip Android devices through local network ADB or remote USB-over-SSH workflows. | Use it for `adb shell`, `push/pull`, `logcat`, `setprop`, `reboot`, and device inspection tasks. |
| `rk-asr` | `rk-asr/` | Transcribes audio files into text with a simple script-based ASR workflow. | Use it when a user wants speech-to-text, audio transcription, or voice recognition results. |
| `rk-tts` | `rk-tts/` | Convert text to audio with a simple scipt-based TTS workflow. | Use it when a user wants text-to-speech. |
| `rk-model-benchmark` | `rk-model-benchmark/` | Benchmarks LLM, CNN models on Rockchip NPU devices such as RK1820 and RK1828. | Use it for inference performance tests, FPS checks, latency measurements, throughput analysis, and NPU frequency experiments. |
| `rk-hwc-troubleshooting` | `rk-hwc-troubleshooting/` | Helps diagnose Rockchip Android HWC and display pipeline issues with reference-driven troubleshooting steps. | Use it for black screens, flicker, corruption, frame drops, crashes, and other graphics/display problems. |
| `rk-binary-image-decoder` | `rk-binary-image-decoder/` | Decodes raw binary image buffers into viewable image files based on parsed filename parameters. | Use it when a user wants to convert a binary dump into an image for inspection or sharing. |
| `rk-iva` | `rk-iva/` | ROCKIVA object detection on RK3588 Linux: one-frame detection from camera or image files (person, pet, vehicle, non-vehicle). | Use it when a user wants camera capture plus detection, or to run IVA detection on a local image. |
