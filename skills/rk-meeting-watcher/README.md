## RK-MEETING-WATCHER

### 功能简介

支持自定义关键词，实时监听会议语音内容。依托 ASR 服务对麦克风音频流进行实时文字转写，持续匹配预设关键词。一旦检测到目标关键词，将通过 QQ 推送提醒消息，及时跟进会议关键信息。



### 麦克风输入

RK3588 开发板自带板载麦克风，但底噪偏高，收音效果一般。为保证监听与识别精度，建议搭配外接 USB 麦克风使用。

板载麦克风及主流 USB 麦克风均依赖 `alsa-utils` 组件，需提前在设备中安装：

```bash
sudo apt update
sudo apt install alsa-utils
```



### 技能配置

将`SKILL.md`和`scripts`目录，推到3588开发板`~/.openclaw/workspace/skills/rk-meeting-watcher`目录下



### 调用示例

推荐通过 QQ 机器人快速交互使用。

#### 用户指令

- 开启监听：`请帮我开启会议监听，关键词“龙虾”`
- 关闭监听：`停止会议监听`

#### 效果说明

系统识别到预设关键词后，将主动推送 QQ 提醒：

`您设置的关键词已触发，请关注会议！`
