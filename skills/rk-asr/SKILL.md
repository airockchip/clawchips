# 音频转录技能

## Workflow

### 步骤 1: 验证输入
1. 确认用户提供了音频文件的路径
2. 没有音频对应的ASR结果，需要转录音频

### 步骤 2: 执行 ASR 识别
在终端中执行以下命令进行音频识别：
```bash
cd scripts && ./run.sh "/path/to/audio.wav"
```

**注意**：将 `/path/to/audio.wav` 替换为实际的音频文件完整路径，其他音频格式如.mp3/.ogg等均可。

### 步骤 3: 解析返回识别结果

识别结果依据音频长度，有如下两种情况：
1. 音频较短时，识别结果以 "text res:\n" 开头，后面跟着识别的文本内容，直接将识别的ASR文本返回给用户
2. 音频较长时，根据输入音频名保存到文件，命令输出为：`ASR result saved to: /userdata/asr/audio_name.txt`，**直接发送文件给用户，严禁读取文件**
3. 如果识别失败，需要提供错误信息

## 输出格式

1. 识别结果以"text res:\n"开头时，直接返回 ASR 识别出的文本内容，不需要额外格式。
2. 识别结果保存到`/userdata/asr/audio_name.txt`时，**直接发送文件给用户，严禁读取文件**

## 错误处理

- **文件不存在**：提示用户"错误：指定的文件 [文件路径] 不存在，请确认文件路径是否正确。"
- **执行失败**：返回命令的错误输出信息

## 示例

### 示例 1: 成功识别

**用户输入**：帮我识别这个音频文件：/home/user/recording.ogg

**执行命令**：

bash

```
cd scripts && ./run.sh "/home/user/recording.ogg"
```


**命令输出**：

text

```
text res:
你好，今天是2024年3月18日，天气晴朗。
```


**返回结果**：
"你好，今天是2024年3月18日，天气晴朗。"


## 安全注意事项

- 音频文件路径中可能包含空格或特殊字符，命令中已使用引号包裹路径以正确处理
